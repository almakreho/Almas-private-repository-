# AIDA_1141_Graded_Labs

Instructor source repository for AIDA 1141 graded labs.

This repository contains student-facing lab briefs, datasets, starter files, rubrics, and submission instructions. It does not contain student submissions or instructor answer keys.

## Student workflow

1. Clone or pull the required lab from this repository.
2. Copy the lab into the student's private AIDA 1141 repository.
3. Complete the work in the private repository.
4. Commit and push the completed work to the private repository.
5. Submit the required Git link or export through D2L.

The private AIDA 1141 repository is the working and evidence repository. D2L remains the official grading-submission location.

## Course continuity

These graded labs provide structured practice and evidence that support the
approved course outcomes.

## Organization

```text
week-04/
week-05/
week-06/
...
```

The active post-Apex numbering is Week 4 = Lab 1, Week 5 = Lab 2, and Week 6 =
Lab 3. These weekly labels replace old Apex-era labels in current student
instructions; they do not change official course records or approved weights.
